# Industrial%20Internship%20Report%20Format

Source: `Z:/minor project/daiict_documents raw/Academic/UG Internships/Industrial-Internship/Summer 2005/Industrial%20Internship%20Report%20Format.pdf`

## Page 1

Industrial Internship Report Format

1. The report is to be submitted to the Industrial Internship Co-ordinator at DA-IICT
by 31st July.

2. The first Page should consist of the Name of Student – Name of Industry- Name
of Supervisor-Duration of Internship.

3. Students should write in brief about:
i. the industry unit where the internship was performed
ii. ICT related issues analysed during the internship
iii. Learnings and experiences about - how ICT is used in carrying out
industrial operations and - how what is learnt in the classroom/
labs is related to how things work in industrial environment, etc.

4. The report (all inclusive) should not exceed 4-A4 size pages.

5. The text should be in 12pt font and the document has to be submitted as a pdf file.
