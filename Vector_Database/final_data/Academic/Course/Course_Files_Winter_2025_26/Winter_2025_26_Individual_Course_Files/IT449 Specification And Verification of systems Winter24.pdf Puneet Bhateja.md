Specification and verification of systems (IT-449)

Course placement: It is a technical elective as well as MnC elective.
Course format: 3-0-0-3
Course contents: Modelling hardware and software systems through transition
systems; modelling concurrency and interleaving in systems; linear time
properties; safety properties; liveness properties; Buchi automata, omega
regular properties; syntax and semantics of LTL (linear temporal logic); syntax
and semantics of CTL (computation tree logic); introduction to model checking
tool SPIN.
Selected readings: (1) Principles of model-checking, MIT Press, Joost Pieter
Katoen, Christel Baier. (2) Logic in computer sciences, modelling and reasoning
about systems, Cambridge press, Michael Huth, Mark Ryan.
Course outcomes:  Designing a software or a hardware system is a nontrivial
task. The design of the system is formally modelled and then verified to gain
confidence. Model checking is one of the predominant techniques for
verification of systems.  This course aims to introduce students about the
mathematical and logical foundations of model checking.
