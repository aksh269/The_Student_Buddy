Moodle courses registration

7. Follow the Below Steps for Moodle courses registration: (First Time registration)

-> Open web browser and enter below URL in address bar:

https://moodle.daiict.ac.in/login/index.php

-> Enter your domain (Daiictpdc) account credentials in username & password type box
-> Fill in Profiles details.

Note: Enter Only institute  email id in Email Address Type box

-> After fill up the all profile details click on Update Profile.
-> After that you will get a mail from moodleadmin@daiict.ac.in for registration confirmation.
-> Click on a link given in mail for confirmation.
-> Now you can logon with your domain account id and password.
