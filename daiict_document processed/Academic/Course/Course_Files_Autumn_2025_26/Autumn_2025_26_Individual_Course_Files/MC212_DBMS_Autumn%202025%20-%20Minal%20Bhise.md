Course Outline 
This course teaches use of Relational Database Management System (RDBMS) to 
understand and solve a wide range of information storage and query processing 
problems in organizations ranging from large corporations to personal applications. The 
course combines the practical aspects of DBMS use with basic theory discussions about   
database design. Students will be learning basic storage and query processing concepts 
of Parallel and Distributed Databases.  As part of the lab assignments/ a project, 
students will learn to build and query the database using DBMS tool for the given 
problem domain (case study).
